# Powershell-Complete-Enviroment-Installation

This is a script for use of the Architecture and Interior Design Labs at the Salt Lake Community College for app installation ONLY!!  Please make a fork repository for any changes you would like to make.

To run this script please make sure that the Set-ExecutionPolicy is set to Bypass.  This current edition (as of 09/08/26) is not signed.  Future editions will be signed and Set-ExecutionPolicy can be set to RemoteSigned for execution.

THIS IS CREATED AS AN UNATTENDED BACKGROUND SCRIPT.  WHICH ALLOWS THE SCRIPT TO CONTINUE INSTALLING APPLICATIONS AFTER A REBOOT WITHOUT LOGON.  A POWERSHELL WINDOW WILL NOT APPEAR AFTER THE FIRST REBOOT.  THE MACHINE WILL REBOOT MULTIPLE TIMES!!!!  PLEASE ALLOW ATLEAST 6 HOURS TO PASS BEFORE INTERUPTING THE INSTALLATION PROCESS.
